3Concept des pages

Fonctionnement en double-page :

  • Page gauche (G) — titre + images
  • Page droite (D) — les 3 bulles langues (FR / EN / NL)

Chaque fichier HTML = une seule page, pour devenir un PDF A4 portrait.

4Codage des pages

Format du code
C{chapitre}S{section}P{page} + G ou D
Début
C0S0P0 = index + toutes les pages avant le chapitre 1
Exemple
C1S1P1G, C1S1P2D, C1S1P3G…
Suffixe
G = page gauche · D = page droite

5Fichiers & dossiers

Dossier
royvanmil.fr/livretechnique/ + sous-dossier img/
Nom de fichier
C1S1P1G.html (sans point)
Règle
1 HTML = 1 page = 1 PDF A4 portrait

Pages fixes du dossier :

  • index.html — index du livre
  • admin.html — cette fiche (mémoire du projet)
  • arbre.html — sommaire cliquable de tout le livre

6Couvertures & mentions

1re de couverture
En couleur, jolie image + titre + les 3 sous-titres (à faire)
4e de couverture
En couleur, même esprit (à faire)
Page mentions
Toutes les infos (auteur, ISBN, copyright…), bien lisible
Mention IA
Affichée lisiblement sur la page mentions — ex. « IA : Yes » / « IA included »

Transparence assurée : le lecteur sait que le livre est réalisé avec l'aide de l'IA.

7Design du livre final

  • Fond blanc, aéré
  • Couleurs claires et froides
  • Bulles à fond couleur très léger, bords arrondis
  • Texte clair et lisible

Aperçu du rendu visé des 3 bulles :

FrançaisTexte explicatif en français.
EnglishExplanatory text in English.
NederlandsUitleg in het Nederlands.

Le HTML de travail n'est pas identique au rendu imprimé final — mais les couleurs et le principe des bulles sont déjà calés ici.
