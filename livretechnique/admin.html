★Méthode de travail — comment on bosse

Règle d'or : chaque fichier de page du livre est PUR — aucun bouton, menu ni flèche dessus. Si on imprime le HTML → on obtient exactement la page du livre. Toute la navigation vit sur des pages séparées (index, arbre, visuels) qui ne sont jamais imprimées.

Principes fixes

  • 1 fichier HTML = 1 page = 1 page PDF A4 portrait. Le HTML est la source unique.
  • Nommage strict : code en MAJUSCULES + .html minuscule (le web est sensible à la casse).
  • Codage : C{chapitre}S{section}P{page} + G (gauche/image) ou D (droite/texte). Début à C0 (index & intro).
  • Une double-page = PnG + PnD (même numéro P). Ex. C1S1P1G (image) + C1S1P1D (texte). Tout est en P1 pour l'instant ; P2, P3… seulement si un même sujet a besoin de pages en plus.
  • Livraison : Claude fournit toujours des fichiers complets (jamais de diff), et discute avant de coder, une étape à la fois.

Gabarit PAGE DROITE (texte) — validé ✅

  • En-tête : titre en noir à gauche + code page à droite, fine ligne de séparation.
  • Dessous : 3 rectangles à bords arrondis qui remplissent toute la page, marges mini.
  • Texte 100 % HTML éditable (pas d'image), FR bleu / EN vert / NL orange, fond léger.
  • Aperçu écran : la feuille se centre sur fond gris quand la page est ouverte seule (désactivé dans le lecteur visuels et à l'impression).

Du HTML au PDF

  • Ouvrir le HTML dans Chrome / Edge → Imprimer → Enregistrer en PDF.
  • Marges : Aucune · Arrière-plans : activés. Rendu identique au HTML.

À faire : marge de reliure (gutter) plus large côté intérieur, inversée entre pages G et D.
